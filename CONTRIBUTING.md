# Contributing to MapKt

Thank you for your interest in contributing! We welcome issues, pull requests, and ideas.

- Before filing a bug, please search existing issues.
- For large changes, open an issue to discuss your proposal.
- Please follow the Code of Conduct.

## Development setup

Check our README

## Pull requests

1. Fork the repo and create a topic branch.
2. Write tests for your changes when possible.
3. Ensure `./gradlew build` passes.
4. Update documentation as needed.
5. Describe your change clearly in the PR template.

## Commit messages

Follow conventional commits style if possible (feat:, fix:, docs:, chore:, etc.).
